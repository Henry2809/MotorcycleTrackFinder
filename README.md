# Motorcycle Track Finder Application
_Four wheels move the body. Two wheels move the soul._
![alt text](image.png)


An interactive web page for motorcycle enthusiasts, specifically for sport bikes. Allow users to find racetracks near their current location. This site will integrate a real-time weather API to check current conditions, such as rain at the track locations, and an API to provide traffic conditions on routes leading to the racetrack, helping users choose the best time to leave. Additional Features include a user profile, allowing the user to store their information such as name, what kind of bike they own, and connect with other people. Track reviews and ratings, allowing users to review and rate the racetrack they visited. Motorcycle maintenance database, a section where users can log maintenance details about their bike such as oil changes, tire replacements, performance of a motorcycle.



**Navigate to the Project Directory**

Use the cd command to change into the project directory (01-trackfinder) where you cloned the repository:

```bash
  cd 01-trackfinder
```

**Install all dependencies**

```bash
  npm install
```

**Run the Development Server**

```bash
  npm run dev
```

**Open the Application**

Once the server is running, open your web browser and visit:

http://localhost:3000/
